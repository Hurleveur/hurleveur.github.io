# Publish exceptions — the allowlist for non-markdown files.
#
# Markdown notes need `publish: true` frontmatter (ExplicitPublish). Files that
# can't carry frontmatter, or whose plugin never reads it (pdf, html, images,
# .canvas, .excalidraw.md, ...) publish ONLY if they match a glob below.
# Anything not listed stays private. Paths are relative to content/, matched by
# the Assets emitter (quartz/plugins/emitters/assets.ts) and, for canvas/
# excalidraw pages specifically, by local-plugins/*/src/publishAllowlist.ts
# (patched forks — upstream reads raw ctx.allFiles with no gate at all).
#
# One glob per line (canvas/excalidraw entries need an exact path match, no
# wildcards). Full-line # comments only.
